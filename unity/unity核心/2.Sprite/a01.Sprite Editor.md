
## Single图片编辑
### SpriteEditor是什么?
顾名思义SpriteEditor就是 精灵图片编辑器
它主要用于编辑2D游戏开发中使用的Sprite精灵图片
它可以用于编辑 图集中提取元素，设置精灵边框，设置九宫格，设置轴心(中心)点等等功能
### 安装 2D Sprite
新版本unity 需要安装2D Sprite包才能使用SpriteEditor
Window-->Package Management -->Package Manager-->2D Sprite
### Single图片编辑 功能讲解
Single图片编辑主要讲解的就是在设置图片时
将精灵图片模式(SpriteMode)设置为Single的精灵图片在SpriteEditor窗口中如何编辑

1. 1.Sprite Editor
   基础图片设置(右下角窗口)
   主要用于设置单张图片的基础属性
   ![[assets/Pasted image 20261105092247.png|323]]
   - Name：名字
   - Position：在图片中偏移位置和宽高
   - Border：边框 用于设置九宫格的四条边
   - Pivot：轴心(中心) 点位置
   - Pivot Unit Mode：轴心点单位模式
     ![[assets/Pasted image 20261105092411.png|311]]
     Normalized：标准化模式 0~1
     Pixels：像素模式
   - Custom Pivot：自定义轴心点 

2. CustomOutline(决定渲染区域)
   自定义边缘线设置，可以自定义精灵网格的轮廓形状
   默认情况下不修改都是在矩形网格上渲染，边缘外部透明区域会被渲染，浪费性能
   使用自定义轮廓，可以调小透明区域，提高性能
   ![[assets/Pasted image 20261105093246.png|321]]
   - Outline Detail 轮廓细节
    控制生成的网格轮廓对精灵形状的**贴合精细度** `0` ~ `1`
   -  Alpha Tolerance 
    设定像素被视为“不透明”的最低 Alpha 阈值（过滤透明像素）
    数值越大：忽略更多的半透明/透明像素，轮廓更“干净”，避开图像透明杂边。
    数值为 `0`（图例中设置）：**任何**非完全透明的像素（Alpha > 0）都会被检测，容易把很淡的边缘也算进轮廓里。
   - Snap (吸附)
    将生成或手动调整的轮廓控制点，自动对齐到最近的**整数像素**上。
    
   **Generate All**：批量为当前纹理中**所有未生成轮廓**的精灵创建轮廓。
   **Copy / Paste / Paste All**：复制当前轮廓设置，粘贴到单个或多个其他精灵上（快速统一形状）。 
- **From Physics Shape (Paste / Paste All)**：将物理形状（Physics Shape）的数据粘贴为渲染轮廓，实现渲染与碰撞体形状同步。

3. CustomPhysics Shape(决定碰撞判断区域)
   自定义精灵图片的物理形状，主要用于设置需要物理碰撞判断的2D图形
   它决定了之后产生碰撞检测的区域
   
4. Secondary Textures(为图片添加特殊效果)
   次要纹理设置，可以将其它纹理和该精灵图片关联
   着色器可以得到这些辅助纹理然后用于做一些效果处理
   让精灵应用其它效果

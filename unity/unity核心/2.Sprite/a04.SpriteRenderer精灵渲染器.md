## Sprite Renderer是什么
Sprite Renderer是精灵渲染器
所有2D游戏中游戏资源(除UI外)都是通过SpriteRenderer让我们看到的
它是2D游戏开发中的一个极为重要的组件
## 2D对象创建
1. 直接拖入Sprite图片
2. 右键创建
3. 空物体添加脚本
## 参数讲解
![[assets/Pasted image 20261105152931.png|381]]
- <font color="#de7802">Sprite:渲染的精灵图片</font>
- Color:定义着色，一般没有特殊需求不会修改
- Filp:水平或竖直翻转精灵图片
- Draw Mode:绘制模式，当尺寸变化时的缩放方式
  ![[assets/Pasted image 20261105153306.png|346]]
  - Simple：简单模式，缩放时整个图像一起缩放
  - Sliced:切片模式，9宫格切片模式，十字区域缩放，4个角不变化一般用于变化不大的纯色图(注意:需要把精灵的网格类型设置为Full Rect)
  - Tiled:平铺模式，将中间部分进行平铺而不是缩放(注意:需要把精灵的网格类型设置为Full Rect)
    ![[assets/Pasted image 20261105153856.png|393]]
    - Continuous:当尺寸变化时，中间部分将均匀平铺
    - Adaptive:当尺寸变化时 类似Simple模式 当更改尺寸达到StretchValue时 中间才开始平铺
- Mask Interaction:与精灵遮罩交互时的方式
  ![[assets/Pasted image 20261105155445.png|335]]
  - None:不与场景中任何精灵遮罩交互
  - Visibleinside Mask:精灵遮罩覆盖的地方可见，而遮罩外部不可见
  - Visible Outside Mask:精灵遮罩外部的地方可见,而遮罩覆盖处不可见
- Sprite Sort Point:计算摄像机和精灵之间距离时，使用精灵中心
  Center还是轴心点Pivot，一般情况下不用修改
- Material:材质，可以使用一些自定义材质来显示一些特殊效果一般情况不修改。默认材质是不会受到光照影响的，如果想要受光照影响，可以选择Default-Diffuse
- <font color="#de7802">Additional Settings:高级设置</font>
  - Sorting Layer:排序层选择，2D 专属排序层级。优先度：排在列表下方的 Sorting Layer，渲染更靠上（挡住上面层）。 用来做大类分层：背景、地面、角色、UI 前景等。<font color="#ff0000">！！和普通 GameObject 的 Layer（物理/射线层）不是同一个东西。</font>
  - Order in Layer:在同一个 Sorting Layer 内部的先后顺序。数值越大：越后绘制，显示在更上层，遮挡同层数值更小的精灵，可以为负数
  - Rendering Layer Mask（渲染层掩码）
    给这个精灵打上渲染标记，配合 Renderer Filter / SRP 的 Render Layer 使用； 用于定向光照、自定义后处理、着色器过滤：灯光、Pass 可以选择只作用于指定 Rendering Layer 的物体。
  > 注意: 不要和 Sorting Layer、普通 Layer 搞混：  
    Sorting Layer：控制 2D 绘制先后（遮挡） 
    Layer：射线、物理碰撞、相机剔除
    Rendering Layer Mask：着色器、光照、渲染管线过滤
 
## 代码设置
```csharp
 GameObject obj = new GameObject();
 SpriteRenderer sr = obj.AddComponent<SpriteRenderer>();
 //动态的改变图片
 sr.sprite = Resources.Load<Sprite>("dead1");
 //动态的加载 图集中的图
 Sprite[] aprs = Resources.LoadAll<Sprite>("RobotBoyDeathSprite");
 sr.sprite = aprs[10];
```

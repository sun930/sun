## 纹理类型主要是设置什么
设置纹理类型主要是为了让纹理图片有不同的主要用途，指明其是用于哪项工作的纹理
## 参数讲解
![[assets/Pasted image 20261104164216.png|347]]
- Defalut 默认纹理，大部分导入的模型贴图都是该类型
  ![[assets/Pasted image 20261104164453.png]]
  sRGB(Color Texture):启用可以将纹理存储在伽马([[../../Other/线性和伽马颜色空间|线性和伽马颜色空间]])空间中(对每一个像素做一次幂函数运算)，帮助我们校准数据，更符合我们肉眼观察的一个规则
  ==Alpha Source:指定如何生成纹理的Alpha通道==
    - None:无论输入纹理是否有Alpha通道，导入的纹理都没有Alpha通道
    - Input Texture Alpha: 输入纹理中的Alpha
    - From Gray Scale:从输入纹理RGB值的平均值生成Alpha
  Alpha Is Transparency:启用可以避免边缘上的过滤瑕疵
- Normal map 法线贴图格式
  ![[assets/Pasted image 20261104172314.png|359]]
  ![[assets/Pasted image 20261104172340.png|323]]
  法线贴图就是在原物体的凹凸表面的每个点上均作法线，法线就是垂直于某个点的切线的方向向量
  (模型更加精致，意味着组成它的三角面片就越多，但是三角面片越多，渲染消耗性能越多，如果一个面数非常多的模型，进入到Unity，如果显卡不好就会卡顿，这个时候一般都不会直接使用精致的模型，会把这个模型变成低模(面数更少的模型)，可能会把几个三角面合成一个，低模会导致模型不够精致，此时就会用到我们的法线贴图。我们会在精细模型上生成一张法线贴图，我们就知道每一个精细的面它的法线是多少，最终变成低模，但是我们在渲染的时候，我们会通过法线贴图(这个法线贴图其实是精模的一些法线信息)，结合着色器算法，让每个点通过这个法线贴图去计算受光照影响的效果，这样可以达到在一个粗糙的模型上使用更精致模型的法线贴图渲染出好的效果)
  - Create From Grayscale:启用此属性可以从灰度高度贴图创建法线贴图
  - Bumpiness:控制凹凸程度，值越大凹凸感越强
  - Filtering:如何计算凹凸值。
    - Smooth:使用标准算法生成法线贴图
    - Sharp:生成比标准模式更锐利的法线贴图
  - Flip Green Channel翻转 G 绿色通道:外部软件（Blender、Substance）导出法线时，有的是 OpenGL 格式，导入 Unity 就需要翻转绿通道，不然凹凸是反的（凹变凸、凸变凹）
- Editor GUIl and Legacy GUI般在编辑器中或者GUI上使用的纹理
- Sprite (2D and UI)2D游戏或者UGUI中使用的格式
  ![[assets/Pasted image 20261104174516.png|324]]
  - Sprite Mode:图像中提取精灵图形的方式
    ![[assets/Pasted image 20261104174553.png]]
    - Single:按原样使用精灵图像
    - Multiple:瓦片模式，如果是图集，使用该选项，可以在 Open Sprite Editor编辑窗口自定义图片
    - Polygon:网格精灵模式
  - Pixels Per Unit:世界控件中的一个举例单位对应多少像素
  - MeshType:网格类型;只有Single和Multiple模式才支持
    ![[assets/Pasted image 20261104195900.png]]
    - FullRect:创建四边形，将精灵显示在四边形上
    - Tight:基于像素Alpha值来生成网格，更加贴合精灵图片的形状任何小于32*32的精灵都使用FulIRect模式，即使设置成Tight模式也是
  - ExtrudeEdges:使用滑动条确定生成的网格中精灵周围流出的区域大小
  - Pivot:精灵图片的轴心点，Single模式才有此选项对应九宫格布局的九个点，还可以自定义
    ![[assets/Pasted image 20261104200035.png|282]]
  -  Generate Physics Shape:启用此选项，Unity会自动根据精灵轮廓生成默认物理性状
    只有Single 和Multiple模式才可使用
  - Open Sprite Editor:编辑Sprite，需要安装2D Sprite包，之后单独讲解
- Cursor 自定义光标
- Cookie 光源剪影格式 灯光 Cookie，给聚光 / 平行光做光斑遮罩、树叶投影纹理
  ![[assets/Pasted image 20261104201918.png|331]]
  ![[assets/Pasted image 20261104201946.png|329]]
- Light Type:应用的光源类型
    一般点光源的剪影需要设置为立方体纹理
    方向光和聚光灯的剪影设置为2D纹理
    - Spotlight:聚光灯类型，需要边缘纯黑色纹理
    - Directional:方向光，平铺纹理
    - Point:点光源，需要设置为立方体形状
- Lightmap 光照贴图格式
- Directional Lightmap：方向型光照贴图（带光照方向信息）
- Shadowmask：阴影遮罩贴图，和 Lightmap 搭配，用于混合光照模式
- Single Channel 纹理只需要单通道的格式
  ![[assets/Pasted image 20261104202543.png]]
  Channel:希望将纹理处理为Alpha还是Red通道
  Alpha:使用Alpha通道，不允许进行压缩
  Red:使用红色通道

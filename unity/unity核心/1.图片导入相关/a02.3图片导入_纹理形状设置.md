## 纹理形状主要是设置什么?
纹理不仅可以用于模型贴图
还可以用于制作天空盒和反射探针
纹理形状设置 主要就是用于在两种模式之间进行切换
## 参数讲解
![[assets/Pasted image 20261104205744.png|357]]
Texture Shape:纹理形状
- 2D:2D纹理，最常用设置，这些纹理将使用到模型和GUI元素上
- Cube:立方体贴图，主要用于天空和和反射探针
  ![[assets/Pasted image 20261104213901.png|343]]
  Mapping:如何将纹理投影到游戏对象上
   - Auto:根据纹理信息创建布局
   - 6FramesLayout:纹理包含标准立方体贴图布局之一排列的六个图像
   - Latitude-Longitude Layout:将纹理映射到2D维度/经度
   - Mirrored Ball:将纹理映射到类似球体的立方体贴图上
  ![[assets/Pasted image 20261104214250.png|346]]
  Convolution Type:纹理的过滤类型
   - None:无过滤
   - Specular:将立方体作为反射探针
   - Diffuse:将纹理进行过滤表示辐照度，可作为光照探针
  Fixup Edge Seams: Convolution Type 为None 和 Diffuse下才有用。解决低端设备上面之间立方体贴图过滤错误
- 2D Array（2D 纹理数组，一组大小相同贴图打包）
  把一张大图按行列切成 N 张子图，在 GPU 里存成数组，Shader 可以用索引array[slice]切换贴图 
  Columns：列数，Rows：行数
  
  用途：瓦片地图图集、帧动画、粒子序列；比多次 SetTexture 性能更好 
  注意：所有切片**宽高必须完全一样**
- 3D（Volume Texture 体积纹理，体渲染）
  逻辑和 2D Array 面板长得一样，但底层是**真正 3D 体积贴图**，采样用`uvw`三维坐标（x,y,z）
  用途：体积雾、体积云、3D 噪声、流体；2D 小游戏几乎碰不到

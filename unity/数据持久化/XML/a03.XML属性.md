## 属性语法
```xml
<!--属性就是在元素标签后面空格 添加的内容-->
<!--注意:属性必须用引号包裹 单引号双引号都可以-->
<Friend name = "野生狗奶过期" age = '22'>我的朋友</Friend>
<!--如果使用属性记录信息 不想使用元素记录 可以如下这样写-->
<Father name = "dad" age = "60"/>
```
## 属性和元素节点的区别
属性和元素节点只是写法上的区别而已我们可以选择自己喜欢的方式来记录数据
```xml
<!--使用元素标签嵌套的形式表示道具信息-->
<Item>
<>
```

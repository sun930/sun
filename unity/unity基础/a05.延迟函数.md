## 核心概念
`Invoke` 系列是 `MonoBehaviour` 内置的**延迟函数**，作用：延时若干秒后执行指定方法，不需要自己写计时器。


|API|作用|
|---|---|
|`Invoke("方法名", 延迟秒数)`|延时指定秒，执行**一次**方法|
|`InvokeRepeating("方法名", 首次延迟, 重复间隔)`|延时后，重复循环执行方法|
|`CancelInvoke()`|取消当前脚本**全部**延迟调用|
|`CancelInvoke("方法名")`|取消指定名字的延迟（不管开启多少次全部取消）|
|`IsInvoking()`|判断当前脚本是否存在任意待执行延迟|
|`IsInvoking("方法名")`|判断某个方法是否有|
## 关键注意事项（高频踩坑）

1. 第一个参数是**字符串写方法名**，不能直接写函数 `Invoke(DelayDoSomething,5)` ❌
2. **Invoke 原生不支持传参**，想要传参需要包装一层函数做中转。
3. 被调用的方法**必须写在当前这个 Mono 脚本里面**，不能直接调用别的脚本对象的函数。
4. 对象失活 / 脚本组件失活：**延迟函数仍然会继续跑！不会停止**
5. GameObject 销毁 / RemoveComponent 移除脚本：延迟函数直接失效，不再执行。
6. 如果在`OnEnable`开启重复 Invoke，建议在`OnDisable`手动`CancelInvoke`，防止对象反复激活导致叠加多次延迟。

### 小技巧：`nameof()`

推荐使用 <font color="#ff0000">`nameof(DelayDoSomething)`</font> 代替手写字符串 `"DelayDoSomething"`。

- 重构改名的时候 IDE 可以自动同步修改，不会出现字符串写错导致 Invoke 静默失效不报错。

```csharp
// 想要延时调用 TestFun(10)
void CallTestFunWrapper()
{
    TestFun(10);
}

// 使用
Invoke(nameof(CallTestFunWrapper), 3);
```

### 对比补充（拓展笔记）

> Invoke 底层基于游戏时间 `Time.time`；`Time.timeScale = 0` 时间暂停时，Invoke 也会暂停。 如果需要不受时间缩放影响的延时，不要用 Invoke，改用 `Coroutine` 协程。

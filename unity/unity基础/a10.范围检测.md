## 回顾：碰撞检测基础

碰撞产生必备条件

1. 至少一个物体拥有**Rigidbody 刚体**
2. 两个物体都要有**Collider 碰撞器**

- **碰撞 Collision**：产生真实物理反弹效果，触发`OnCollisionXXX`系列函数
- **触发 Trigger**：勾选碰撞器 Is Trigger，无物理撞击，触发`OnTriggerXXX`系列函数
- 碰撞检测：用于实体物体之间需要真实物理交互的场景
## 一、什么是范围检测

> 没有真实碰撞器物体，**瞬时判断某个空间范围内有哪些物体**，常用于技能伤害、AOE、攻击判定。

示例场景

- 地刺魔法：前方 5 米范围内敌人扣血
- 近战挥砍：前方圆形范围内目标受到伤害

核心逻辑：

1. 指定一块空间区域（盒子 / 球体 / 胶囊）
2. API 瞬时执行一次空间查询
3. 获取范围内所有物体的碰撞器，做业务逻辑（掉血、眩晕等）

✅ 被检测对象要求：**必须带 Collider 碰撞器** ⚠️ 重要注意

1. 范围检测 API 执行时才做一次计算，**瞬时生效，不会持续检测**；如果要每帧检测，写在 Update 中。
2. 不会真实生成碰撞器，只是物理引擎内部空间计算。

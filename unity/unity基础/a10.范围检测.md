## 回顾：碰撞检测基础

碰撞产生必备条件

1. 至少一个物体拥有**Rigidbody 刚体**
2. 两个物体都要有**Collider 碰撞器**

- **碰撞 Collision**：产生真实物理反弹效果，触发`OnCollisionXXX`系列函数
- **触发 Trigger**：勾选碰撞器 Is Trigger，无物理撞击，触发`OnTriggerXXX`系列函数
- 碰撞检测：用于实体物体之间需要真实物理交互的场景
## 一、什么是范围检测

**一句话：瞬时查询指定空间范围内，所有带碰撞器的物体。不会生成真实碰撞体，没有物理碰撞效果。**

适用场景：AOE 技能、近战挥砍、地刺、爆炸伤害、区域拾取。 逻辑：划定一块空间 → 执行一次查询 → 获取范围内物体 → 执行扣血 / 特效等逻辑。

✅ 前提：**被检测对象必须拥有 Collider，不需要刚体** ⚠️ 特点：

1. 瞬时执行，代码运行那一刻才做一次检测；持续检测写在`Update`
2. 只是物理引擎空间计算，不会产生真实碰撞物体

## 二、三大范围检测 API

每组 API 都有两个版本：

1. `OverlapXXX()`：返回`Collider[]`，会产生 GC，适合偶尔调用
2. `OverlapXXXNonAlloc()`：复用传入数组，**无 GC，Update 高频优先用**

 **OverlapBox 盒状范围检测**
```csharp
Collider[] Physics.OverlapBox(
    Vector3 center,         // 盒子中心点
    Vector3 halfExtents,    // 盒子半长宽高！不是完整尺寸
    Quaternion rotation,    // 盒子旋转
    int layerMask = -1,     // 层级掩码，筛选检测层
    QueryTriggerInteraction // 是否检测触发器
);
```
**OverlapSphere 球形范围检测**
```csharp
Collider[] Physics.OverlapSphere(
    Vector3 center,
    float radius,
    int layerMask = -1,
    QueryTriggerInteraction
);
```
**OverlapCapsule 胶囊范围检测**
```csharp
Collider[] Physics.OverlapCapsule(
    Vector3 point0, // 胶囊上端半球中心
    Vector3 point1, // 胶囊下端半球中心
    float radius,
    int layerMask = -1,
    QueryTriggerInteraction
);
```
QueryTriggerInteraction 枚举：

- `UseGlobal`：跟随项目 Physics 全局设置
- `Collide`：可以检测到触发器 Collider
- `Ignore`：忽略所有触发器 Collider

> <font color="#00b0f0">所有`XXXNonAlloc`共用这套规则</font>

1. 结果从数组下标 0 开始写入传入的数组
2. **不会清空数组旧数据**，未覆盖位置保留上次残留内容
3. 返回值：**本次真实命中的碰撞体数量**
4. 遍历必须使用返回值做循环上限，**严禁使用数组.Length**
5. 返回值 = 0（没有命中）：数组完全不变，**禁止读取数组内容**
6. 命中数量超过数组容量：超出部分直接丢弃

## 三、LayerMask 层级掩码（位运算）

int 一共 32 个 bit 位，**每一位对应一个层级开关**，1 = 检测该层，0 = 忽略该层。 `1 << n` 等价数学：\(2^n\)，把二进制的 1 移动到第 n 号 bit 位。

|层级编号 n|层名|表达式|十进制|二进制有效位|
|---|---|---|---|---|
|0|Default|`1 << 0`|1|`0000 0001`|
|1|TransparentFX|`1 << 1`|2|`0000 0010`|
|2|Ignore Raycast|`1 << 2`|4|`0000 0100`|
|4|Water|`1 << 4`|16|`0001 0000`|
|5|UI|`1 << 5`|32|`0010 0000`|
- 获取层级编号：`LayerMask.NameToLayer("UI")` 根据层名字拿到 n
- 单层检测：`1 << LayerMask.NameToLayer("UI")`

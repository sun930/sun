## 参数
- <font color="#ff0000">Loop </font>
  是否终点起始自动相连
- <font color="#ff0000">Positions</font>
  线段的点(世界坐标)
- <font color="#ff0000">线段宽度曲线调整</font>
- <font color="#ff0000">Color</font>
  颜色变化
- <font color="#ff0000">Corner Vertices (角顶点,圆角)</font>
  此属性指示在一条线中绘制角时使用了多少额外的顶点。增加此值，使线角看起来更圆。
- <font color="#ff0000">End Cap Vertices (终端顶点,圆角)</font>
  终点圆角
- Alignment  对齐方式
  1. View 视点
     线段对着摄像机
  2. Transform Z
     线段面向其Z轴
- Texture Mode 纹理模式
  1. Stretch 拉伸
      沿整条线映射纹理一次
  2. Tile 瓷砖平铺
      不停地重复纹理
      按现实米数重复。例如设置 1 米重复一张贴图；线条 5 米长，就会出现 5 份贴图。
  3. Distribute Per Segment 分配执行
     整张纹理分配给整条线，不管每一段实际距离长短。顶点密的地方也不会挤压纹理，整条线是一整张图。
  4. Repeat Per Segment 重复显示
     **每两个点之间，单独贴一遍完整纹理**。折线有几段，就重复几次贴图。
  5. Static 静态
     UV 固定锁死。线条顶点改动，贴图不会跟随变化。动态移动的线不要选这个。
- Shadow Bias
  阴影偏移
- Generate Lighting Data
  生成光源数据
- <font color="#ff0000">Use World Space</font>
  是否使用世界坐标系
- <font color="#ff0000">Materials</font> 
  线使用的材质球
- Lighting 光照影响
  1. Cast Shadows 是否开启阴影
    - `On`：线条会向其它物体投射阴影
	- `Off`：不投射阴影（拖尾、特效线条一般关闭，省性能）
	- `Two Sided`：双面都可以投射阴影
	- `Shadows Only`：只输出阴影，线条本身不可见
  2. Static Shadow Caster 静态阴影投射器
    - 勾选：把这条线当作**静态物体参与烘焙阴影**
	- 只对完全不动的线条生效；动态移动的线条**不要勾选**，阴影不会跟随更新。
- Probes（光照探针）
  1. Off：关闭，不受环境烘焙光影响。特效拖尾首选
  2. Blend Probes：自动混合周围探针，动态物体默认
  3. Use Proxy Volume：代理体积，大物体/长线条批量计算光照，需挂载对应组件
  4. Custom Provided：脚本手动提供光照数据，高级渲染使用
- Additional Settings 附加设置
  1. Motion Vectors 运动矢量（用于运动模糊/TAA）
     - Camera Motion Only：仅相机运动输出矢量（默认）
     - Per Object Motion：物体自身移动也输出，需要线条运动模糊开启
     - Force No Motion：关闭运动矢量
  2. Dynamic Occlusion：动态遮挡剔除，被挡住时跳过渲染，优化性能。
  3. Sorting Layer：渲染排序大层，控制线条在哪个层级。
  4. Order in Layer：同层渲染顺序，数值越大绘制越靠上。
  5. Rendering Layer Mask：渲染层掩码，配合相机，控制哪个相机可以渲染这条线。

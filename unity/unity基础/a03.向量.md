
## 向量模长和单位向量
### 向量基础
标量: 有数值大小 没有方向
<font color="#ff0000">向量: 有数值大小 有方向的矢量</font>
一维,二维,三维
![[assets/Pasted image 20260910160621.png|285]]
<font color="#ff0000">注意:向量在空间中有无数条可以随意移动</font>

#### 两点决定一向量
![[assets/Pasted image 20260910161913.png|361]]
A点: (Xa,Ya,Za)
B点:(Xb,Yb,Zb)

从A指向B的向量为AB向量
B-A = (Xb-Xa, Yb-Ya, Zb-Za)
从B指向A的向量为BA向量。
A-B = (Xa-Xb, Ya-Yb, Za-Zb)
<font color="#ff0000">口诀:终点减起点</font>

#### 零向量和负向量
零向量
<font color="#ff0000">(0,0,0)</font>
零向量是唯一一个大小为0的向量

负向量
(x,y,z)的负向量为(-x,-y,-z)
负向量和原向量大小相等
负向量和原向量方向相反
### 向量模长
向量的模长就是向量的长度:
<font color="#ff0000">向量是由两个点算出，所以向量的模长就是两个点的距离</font>

模长公式:
A向量(x,y,z)
$$ |\vec v|=\sqrt{x^2+y^2+z^2} $$
```csharp
AB.print(AB.magnitude);
```

### 单位向量
<font color="#ff0000">模长为1的向量为单位向量</font>
任意一个向量经过归一化就是单位向量
<font color="#ff0000">只需要方向，不想让模长影响计算结果时使用单位向量</font>

输入向量：$\vec v=(x,y,z)$ 向量模长：$|\vec v|=\sqrt{x^2+y^2+z^2}$ 单位向量（归一化结果）： $$ \hat{\boldsymbol v} = \frac{\vec v}{|\vec v|}= \left( \frac{x}{\sqrt{x^2+y^2+z^2}},\; \frac{y}{\sqrt{x^2+y^2+z^2}},\; \frac{z}{\sqrt{x^2+y^2+z^2}} \right) $$
```csharp
print(AB.normalized);
print(AB / AB.magnitude);
```

## 向量加减乘除

### 向量加法
向量A(Xa,Ya,Za)
向量B(Xb,Yb,Zb)
<font color="#ff0000">A + B = (Xa + Xb, Ya + Yb, Za + Zb)</font>

Vector3 + Vector3的意义
- 位置 + 位置 两个位置相加没有任何意义
- <font color="#ff0000">向量 + 向量</font>
  两个向量相加得到一个新向量
  **向量+向量=向量**
  ==口诀:向量相加，首尾相连==

  ![[assets/Pasted image 20260910171911.png|430]]
- <font color="#ff0000">位置 + 向量</font>
  位置加向量得到一个新位置
  **位置+向量=位置**
  **向量+位置=位置**
  ==口诀:位置和向量相加=平移位置==
  ![[assets/Pasted image 20260910172126.png|421]]
### 向量减法
向量A(Xa,Ya,Za)
向量B(Xb,Yb,Zb)
A - B = (Xa - Xb, Ya - Yb,Za - Zb)

Vector3 - Vector3的意义
- <font color="#ff0000">位置 - 位置</font>
  两个位置相减得到一个新向量
  **位置-位置=向量**
  ==口诀:两点决定一向量。终点-起点==
  ![[assets/Pasted image 20260910172442.png|423]]
- <font color="#ff0000">向量 - 向量</font>
  两个向量相减得到一个新向量
  **向量-向量=向量**
  ==口诀:向量相减，头连头，尾指尾A-B=B头指A头==
  ![[assets/Pasted image 20260910172741.png|425]]
- <font color="#ff0000">位置 - 向量</font>
  位置减向量相当于加负向量
  **位置+(-向量)=位置**
  ==口诀:位置减向量=平移位置==
  ![[assets/Pasted image 20260910173318.png|428]]
- 向量 - 位置 向量减位置没有任何意义
### 向量乘除
向量只会和标量进行乘除法运算
向量A(x,y,z)
标量a
A * a=(x * a,y * a,z * a)
A/a =(x/a, y/a,z/a)

向量 * or / 标量 = 向量
向量 * or / 正数, <font color="#ff0000">方向不变，放大缩小模长</font>
向量 * or / 负数, <font color="#ff0000">方向相反，放大缩小模长</font>
向量 * 0，<font color="#ff0000">得到零向量</font>
### 向量点乘
向量A (Xa,Ya,Za)
向量B (Xb,Yb,Zb)
A . B = Xa * Xb + Ya * Yb + Za * Zb
向量·向量=标量
#### 几何意义
点乘可以得到一个向量
在自己向量上<font color="#ff0000">投影的长度</font>
<font color="#ff0000">点乘结果>0两个向量夹角为锐角</font>
<font color="#ff0000">点乘结果=0两个向量夹角为直角</font>
<font color="#ff0000">点乘结果 小于 0两个向量夹角为钝角</font>

我们可以用这个规律判断敌方的大致方位

### 向量叉乘
<font color="#ff0000">向量 x 向量=向量</font>
向量A(Xa,Ya,Za)
向量B(Xb,Yb,Zb)
A x B = (X,Y,Z)
X= YaZb - ZaYb
Y=ZaXb - XaZb
Z= XaYb - YaXb
![[assets/Pasted image 20260911093738.png|491]]
#### 几何意义
A x B得到的向量同时垂直A和B
A x B向量垂直于A和B组成的平面
A x B = -(BxA)
![[assets/Pasted image 20260911095402.png|458]]
```csharp
//判断的是OA向量和OB向量关系
//谁 叉乘 谁 叉乘后面的在前面的左侧还是右侧
Vector3 C = Vector3.Cross(A.position, B.position);
if (C.y > 0)
{
    print("B在A的右侧");
}
else
{
    print("B在A的左侧");
}

```
## 插值运算

### 线性插值
<font color="#00b0f0">Vector3.Lerp(start, end, t);</font>
对两个点进行插值计算
t的取值范围为0~1
<font color="#ff0000">公式: result = start + (end - start) * t</font>
注:Mathf里面的Lerp是改一个值，Vector3里面的是改三个值
#### 线性插值应用
<font color="#ff0000">1.每帧改变start的值(先快后慢)</font>
<font color="#ff0000">2.每帧改变的值(匀速)</font>

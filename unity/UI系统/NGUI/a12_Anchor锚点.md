## 老版参数
![[assets/Pasted image 20261019155823.png|225]]
- UICamera  关联UI摄像机
- Container  控制的容器对象
- Side  9宫格位置
- Run Only Once
  是否只对齐一次。
  一般情况下设备分辨率都定死的
  横屏竖屏也是定死的
  所以勾选
  除非分辨率要变化才取消勾选
- Relative Offset  相对比例偏移位置(0~1)
- Pixel Offset  像素偏移位置

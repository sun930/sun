## 参数
![[assets/Pasted image 20261014152413.png|301]]
![[assets/Pasted image 20261014152431.png|302]]
- <font color="#ff0000">Options  下拉列表显示内容(空一行表示加一个)</font>
- <font color="#ff0000">Position  列表出现位置</font>
  ![[assets/Pasted image 20261014152712.png|292]]
  自动(建议自动让其自动判断)
  向上、向下
- Selection选中操作
  ![[assets/Pasted image 20261014152840.png|294]]
  按下选中、点击选中
- <font color="#ff0000"> Alignment  对其方式</font>
  ![[assets/Pasted image 20261014152930.png|294]]
  自动对齐、左对齐、居中对齐、右对齐、调整会自动变化
- <font color="#ff0000">Open on 下拉列表打开方式</font>
  ![[assets/Pasted image 20261014162338.png]]
  点击或者触碰、右键、双击、手动(相当于关闭。自己代码处理，一般不选择)
- <font color="#ff0000">On Top 始终显示在所有面板之前</font>
  默认选择
- Localized  是否将对弹出列表的值进行本地化
- <font color="#ff0000">Keep Value  始终保持有列表中的某个默认值</font>
- <font color="#ff0000">Font</font>
  - <font color="#ff0000">Font 字体</font>
  - <font color="#ff0000">Font Size</font>
  - <font color="#ff0000">Texture 字体颜色</font>
  - Padding 偏移位置
  - Modifier 修饰方式 强制大小写字母
    ![[assets/Pasted image 20261014153311.png|285]]
    没有限制、大写字母、小写字母、自定义
- <font color="#ff0000">Atlas</font>
  - <font color="#ff0000">Atlas 图集</font>
  - <font color="#ff0000">Background  下拉列表 背景图</font>
  - <font color="#ff0000">Highlight  下拉列表选中图</font>
  - <font color="#ff0000">Background  背景颜色叠加</font>
  - <font color="#ff0000">Highlight  选中 高亮叠加家宴</font>
  - <font color="#000000">Overlap  弹出窗口边框与打开它的内容重叠的数量</font>
  - <font color="#000000">Animated  是否有默认的弹出动画禁用可以节约性能</font>

## 参数

![[assets/Pasted image 20261012103453.png]]

- Atlas 选择使用的图集
- Sprite 选择使用图集中的精灵图片
- Material 材质，一般不修改
- Fiexd Aspect 固定宽高比
	  不管如何变化尺寸
	  适中保持宽高比
- Type 图片类型
  ![[assets/Pasted image 20261012103834.png]]
  - Simple 普通模式 缩放会拉伸
  - Sliced 切片模式 可九宫格缩放
    ![[assets/Pasted image 20261012105041.png]]
    缩放拉伸不会改变四个角
  - Tiled 平铺模式 图片重复绘制
  - Filed 填充模式 可以作CD 进度条等
    ![[assets/Pasted image 20261012104120.png]]
    填充方式、水平、竖直、90度、180度、360度
 - Advanced 高级模式 可以把图片分成5个部分分别设置模式
 - Flip 翻转模式
   水平、竖直、水平竖直
 - Gradlient 渐变色
   勾选后自动渐变上部颜色和下部颜色
 - Color Tint 颜色叠加
